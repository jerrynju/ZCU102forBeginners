## 关键里程碑与时间估算

| 阶段 | 里程碑 | 参考工期 |
|-----|-----|---------|
| 需求 & 架构 | PRD冻结、架构评审通过 | 1-2个月 |
| FPGA/软件开发 | ZCU102功能验证完成 | 3-6个月 |
| 系统集成验证 | 性能指标全部达标 | 1-2个月 |
| 定制板设计 | DVT测试通过 | 3-5个月 |
| 认证 | 证书取得 | 2-4个月 |
| 量产准备 | PVT通过，产线就绪 | 1-2个月 |
| **合计** | **首批交付** | **12-21个月** |

## 常见风险与规避策略

| 风险 | 概率 | 影响 | 规避策略 |
|-----|-----|-----|---------|
| FPGA时序收敛困难 | 中 | 高 | 早期做时序预算，控制逻辑密度 |
| DDR4信号完整性问题 | 中 | 高 | PCB阶段邀请Xilinx FAE评审 |
| 认证不通过返工 | 低 | 高 | DVT阶段做Pre-scan |
| 芯片供货短缺 | 中 | 高 | 提前锁货，做国产替代验证 |
| 量产固件安全漏洞 | 低 | 极高 | 安全左移，SDL流程嵌入开发周期 |
| 竞品技术超越 | 中 | 中 | 模块化设计，算法可替换升级 |
