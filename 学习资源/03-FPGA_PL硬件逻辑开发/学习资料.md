## 二、Vivado开发流程

### 1. 工程搭建步骤
1. 创建工程，选择ZCU102开发板 (xc7z104-clg484-2-e)
2. 添加Zynq UltraScale+ MPSoC IP
3. 运行Board Automation完成基本配置
4. 配置PS：使能所需外设 (USB、SDIO、GEM、UART、I2C等)
5. 添加自定义AXI IP或第三方IP
6. 连接AXI Interconnect/SmartConnect
7. 添加约束文件 (XDC)：引脚分配、时序约束

### 2. 关键HLS优化指令
```c
#pragma HLS PIPELINE II=1        // 流水线，最优吞吐
#pragma HLS DATAFLOW             // 任务级并行
#pragma HLS ARRAY_PARTITION      // 数组分区
#pragma HLS INTERFACE axis       // AXI-Stream接口
#pragma HLS INTERFACE s_axilite  // AXI4-Lite控制接口
#pragma HLS UNROLL               // 循环展开
```

### 3. 综合实现与时序收敛
- 时序报告检查：确保WNS >= 0
- 时序违例处理：增加流水线级数、优化关键路径、调整Pblock约束
- 资源使用率控制：LUT < 80%，留余量给布线
