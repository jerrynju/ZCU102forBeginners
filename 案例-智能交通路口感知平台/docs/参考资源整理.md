```
重要 pragma 指令：
#pragma HLS PIPELINE II=1        // 流水线，II=1最优吞吐
#pragma HLS DATAFLOW             // 任务级并行（多级pipeline）
#pragma HLS ARRAY_PARTITION ...  // 数组分区（提升并发访问）
#pragma HLS INTERFACE axis ...   // AXI-Stream 接口
```

## 3. 嵌入式 Linux / BSP

| 文档编号 | 文档名称 | 链接 | 重要程度 |
|----------|----------|------|----------|
| UG1144 | PetaLinux Tools Reference Guide | [访问](https://docs.amd.com/r/en-US/ug1144-petalinux-tools-reference-guide) | ★★★★★ |

**UG1144 关键工作流：**
```bash
# 1. 创建项目
petalinux-create -t project --template zynqMP -n my_project

# 2. 导入 XSA
petalinux-config --get-hw-description=./system.xsa

# 3. 内核配置
petalinux-config -c kernel

# 4. rootfs 配置（添加 vitis-ai-library, opencv 等包）
petalinux-config -c rootfs

# 5. 编译
petalinux-build

# 6. 生成启动镜像
petalinux-package --boot --fsbl --fpga --u-boot --force

# 7. 生成 SDK（交叉编译工具链）
petalinux-build --sdk
petalinux-package --sysroot -s ./images/linux/sdk.sh
```

**设备树常用节点（DTS 片段）：**
```dts
/* 预留内存（视频缓冲 + R5 OpenAMP 共享）*/
reserved-memory {
    #address-cells = <2>;
    #size-cells = <2>;
    ranges;
    video_buf: video_buf@80000000 {
        no-map;
        reg = <0x0 0x80000000 0x0 0x0C000000>; /* 192MB */
    };
    rpmsg_shm: rpmsg_shm@B8000000 {
        no-map;
        reg = <0x0 0xB8000000 0x0 0x08000000>; /* 128MB */
    };
};

/* OpenAMP R5 远程处理器 */
remoteproc0: remoteproc@0 {
    compatible = "xlnx,zynqmp-r5-remoteproc";
    xlnx,cluster-mode = <0>;
    memory-region = <&rpmsg_shm>;
};
```

## 4. AI 推理 / DPU

| 文档编号 | 文档名称 | 链接 | 重要程度 |
|----------|----------|------|----------|
| UG1414 | Vitis AI User Guide | [访问](https://docs.amd.com/r/en-US/ug1414-vitis-ai) | ★★★★★ |
| PG338 | Deep Learning Processing Unit (DPU) IP Product Guide | [访问](https://docs.amd.com/r/en-US/pg338-dpu) | ★★★★★ |

**Vitis AI 量化编译完整流程：**
```python
# Step 1: PTQ 量化（PyTorch）
from pytorch_nndct.apis import torch_quantizer

# 校准阶段
quantizer = torch_quantizer('calib', model, input_args,
                            quant_config_file='quant_config.json')
calib_model = quantizer.quant_model
for batch in calib_loader:
    calib_model(batch)
quantizer.export_quant_config()

# 验证阶段
quantizer = torch_quantizer('test', model, input_args,
                            quant_config_file='quant_config.json')
acc = evaluate(quantizer.quant_model, val_loader)

# 导出 xmodel
quantizer.export_xmodel(output_dir='./quantized')

# Step 2: 编译 xmodel（针对 ZCU102 DPU B4096）
vai_c_xir \
  -x quantized/YoloV8s_int.xmodel \
  -a /opt/vitis_ai/compiler/arch/DPUCZDX8G/ZCU102/arch.json \
  -o ./deploy \
  -n traffic_yolov8

# Step 3: VART 推理（C++）
auto graph   = xir::Graph::deserialize("./deploy/traffic_yolov8.xmodel");
auto subgraph = get_dpu_subgraph(graph.get());
auto runner  = vart::Runner::create_runner(subgraph, "run");
auto inputs  = runner->get_inputs();
auto outputs = runner->get_outputs();
inputs[0]->copy_from_host(frame_nv12.data(), frame_nv12.size());
auto [job_id, ok] = runner->execute_async(inputs, outputs);
runner->wait(job_id, -1);
```

**DPU B4096 关键参数（PG338）：**
| 参数 | 值 |
|------|----|
| DPU 型号 | DPUCZDX8G（Zynq UltraScale+ 专用）|
| 算力配置 | B4096（4096 MAC 单元）|
| 工作频率 | 300 MHz |
| 算力 | 2.5 TOPS (INT8) |
| 精度 | INT8 |
| 内存带宽需求 | AXI HP @ 128bit |
| Pblock 建议 | CLOCKREGION_X0Y3:X3Y4 |

```python
from ultralytics import YOLO
model = YOLO('yolov8s.pt')
model.train(
    data='traffic.yaml',
    epochs=300,
    imgsz=640,
    batch=32,
    optimizer='AdamW',
    lr0=0.001,
    # 数据增强
    hsv_h=0.015, hsv_s=0.7, hsv_v=0.4,
    fliplr=0.5,
    mosaic=1.0,
    mixup=0.15,
    copy_paste=0.1,
    close_mosaic=15,
    # 硬件
    device='0',
    amp=True,
)
# 导出 ONNX（Vitis AI 量化使用）
model.export(format='onnx', opset=13, simplify=True)
```

```
ZCU102 入门 → UG1182（了解开发板）
              → UG1085（了解芯片架构）

```

```
              → UG1037（AXI 协议精通）
              → PG232（MIPI CSI-2 实战）
```

```
边缘 AI      → UG1414（Vitis AI 完整流程）

              → YOLOv8 训练 → PTQ 量化 → DPU 部署

```

### 系统架构师
```
全栈能力     → 本案例完整文档（docs/01 ~ docs/08）
              → 重点：DDR4 内存映射、零拷贝数据通路

              → 重点：FreeRTOS R5 实时控制
```
