# 仿真验证指南

EdgeVision-T1 支持在无额外硬件（无 FPGA 比特流、无真实摄像头、无 CAN 线）的情况下，
在 ZCU102 A53 核心（PetaLinux）或开发 PC（x86 Linux）上完成完整闭环验证。

---

## 1. 仿真架构

```
┌─────────────────────────────────────────────────────────────────┐
│                    仿真层（sim/ Python 模块）                   │
│                                                                 │
│  SceneGenerator  →  MockDetector  →  ByteTracker  →  EventDetector
│  [合成路口场景]     [模拟检测误差]    [多目标跟踪]    [事件判断]
│       ↓                                                ↓        │
│  SignalFSM (Python)                               MQTTReporter  │
│  [Webster自适应配时]  ←── 排队长度 ──────────────  [本地Broker] │
│       ↓                                                         │
│  vcan0 (可选)                                                   │
│  [虚拟CAN帧]                                                    │
└─────────────────────────────────────────────────────────────────┘
         ↕ 与 C++ 主应用 --sim 模式完全对应
┌─────────────────────────────────────────────────────────────────┐
│               C++ 仿真模式（--sim 启动参数）                    │
│  SimFrameManager  →  InferenceEngine(mock)  →  EventDetector   │
│  [合成NV12帧/视频]    [无DPU，CPU推理]          [相同业务逻辑]  │
└─────────────────────────────────────────────────────────────────┘
```

**关键设计：** 仿真层与硬件层共用同一套业务逻辑代码（ByteTrack、事件检测、
信号灯 Webster 算法、MQTT Schema）。仿真只替换了最底层的数据采集接口，
确保验证的是真实商业逻辑，而非仿真专用代码。

## 2. 快速开始

### 2.1 一键配置环境

```bash
# 在 ZCU102 A53 或开发 PC 上执行：
cd 案例-智能交通路口感知平台
sudo bash scripts/setup_sim_env.sh
```

该脚本完成：
- 安装 Python 依赖（numpy / opencv-python-headless / paho-mqtt）
- 配置 vcan0 虚拟 CAN 接口（需要 root）
- 启动本地 mosquitto MQTT broker
- 运行环境验证

### 2.2 运行完整仿真

```bash
# 方案一：一键运行所有测试 + 仿真
bash scripts/run_full_sim.sh

# 方案二：手动运行单项
python3 sim/traffic_sim.py --frames 600 --fast   # 600帧快速仿真
python3 sim/traffic_sim.py --frames 300           # 300帧实时仿真（30fps节奏）

# 方案三：运行集成测试
python3 tests/e2e_integration.py -v

# 方案四：带MQTT上报
python3 sim/traffic_sim.py --mqtt localhost --frames 300 --fast
```

### 2.3 查看仿真帧（可选）

```bash
# 启用帧保存（每3秒保存一帧到 /tmp/）
python3 sim/traffic_sim.py --frames 300 --save-frames

# 查看生成的帧
ls /tmp/sim_*.jpg

# 如果有图形界面，实时显示
python3 sim/traffic_sim.py --frames 300 --display
```

## 3. 闭环验证内容

### 3.1 Python 仿真（独立运行，无需编译）

| 验证项 | 测试内容 | 通过标准 |
|--------|----------|----------|
| T01 场景生成 | 合成路口帧、GT格式、信号相位 | 帧尺寸正确、GT有效 |
| T02 检测器 | 召回率、精确率、延迟 | 召回率≥70%、延迟<50ms |
| T03 跟踪器 | 跨帧ID关联、轨迹连续性 | 有长轨迹（≥5帧）、无重复ID |
| T04 事件检测 | 闯红灯、违停检出 | 检出率>0（相对GT） |
| T05 信号FSM | 相位切换序列、Webster响应 | 15s内切换≥1次 |
| T06 完整管道 | 端到端300帧FPS、延迟 | FPS≥20、延迟<50ms |
| T07 可复现性 | 相同种子输出一致 | 帧完全一致 |

### 3.2 C++ 仿真模式（需交叉编译）

```bash
# 在 PetaLinux SDK 环境下交叉编译
source /opt/petalinux-2023.1/sdk/environment-setup-aarch64-xilinx-linux
cd software/app
mkdir build-sim && cd build-sim
cmake .. -DSIM_MODE=ON -DCMAKE_BUILD_TYPE=Debug
make -j4

# 在 ZCU102 上运行（不需要 FPGA 比特流）
./traffic_edge --sim
./traffic_edge --sim --sim-video /mnt/test_video.mp4
```

### 3.3 vcan0 CAN 总线验证

```bash
# 配置虚拟 CAN
sudo modprobe vcan
sudo ip link add dev vcan0 type vcan
sudo ip link set up vcan0

# 后台监听
candump vcan0 &

# 运行仿真（带 CAN 输出）
python3 sim/traffic_sim.py --vcan --frames 300

# 应看到形如以下的 CAN 帧（信号灯相位命令）：
#   vcan0  101   [4]  00 1E 01 00   （NS_GREEN 30s 自适应模式）
#   vcan0  101   [4]  01 02 01 00   （NS_YELLOW 2s）
```

### 3.4 MQTT 数据链路验证

```bash
# 在另一个终端订阅所有主题
mosquitto_sub -h localhost -t "traffic/edge/#" -v

# 运行仿真（带MQTT上报）
python3 sim/traffic_sim.py --mqtt localhost --frames 300 --fast

# 应看到每10秒一条流量统计消息：
# traffic/edge/sim/sim/sim001/flow
# {"interval_s": 10, "counts": {"car": 45, ...}, "queue_m": 23.5, ...}
```

## 4. ZCU102 实机部署验证

### 4.1 最低硬件要求（无额外硬件）

| 组件 | 要求 | 说明 |
|------|------|------|
| ZCU102 | A53 核心运行 | 不需要 FPGA 比特流 |
| SD卡/eMMC | PetaLinux 镜像 | 最小 8GB |
| 网线（可选）| 通过 PS-GEM 访问 | 用于 SSH 和 MQTT |
| USB串口 | 调试输出 | UART0 115200 baud |

### 4.2 在 ZCU102 上运行 Python 仿真

```bash
# 1. 将项目文件复制到 ZCU102
scp -r 案例-智能交通路口感知平台/ root@192.168.1.100:/home/root/

# 2. SSH 登录
ssh root@192.168.1.100

# 3. 安装依赖（PetaLinux 已有 Python3）
pip3 install numpy opencv-python-headless paho-mqtt

# 4. 运行仿真
cd /home/root/案例-智能交通路口感知平台
python3 sim/traffic_sim.py --frames 300 --fast

# 5. 运行集成测试
python3 tests/e2e_integration.py -v
```

### 4.3 性能基准（ZCU102 A53）

| 测试项 | 期望值 | 实测示例 |
|--------|--------|----------|
| 场景生成 FPS | ≥ 60 fps | ~120 fps |
| MockDetector FPS | ≥ 100 fps | ~200 fps |
| 完整管道 FPS（fast模式）| ≥ 30 fps | ~50 fps |
| 完整管道 FPS（实时模式）| = 30 fps | 30 fps（限速）|

## 5. 故障排除

### Q: `import cv2` 失败
```bash
pip3 install opencv-python-headless  # 无GUI版
# 或在 AArch64
pip3 install opencv-python-headless --extra-index-url https://pypi.tuna.tsinghua.edu.cn/simple/
```

### Q: `vcan0` 接口不存在
```bash
sudo modprobe vcan
sudo ip link add dev vcan0 type vcan
sudo ip link set up vcan0
# 如果内核不支持，仿真会自动跳过CAN验证（不影响其他测试）
```

### Q: MQTT 连接失败
```bash
# 检查 mosquitto 是否运行
pgrep mosquitto || mosquitto -c /tmp/mosquitto_sim.conf -d
# 仿真不依赖MQTT，--mqtt 参数可省略
```

### Q: 内存不足（在 ZCU102 上）
```bash
# 减少帧数
python3 sim/traffic_sim.py --frames 100 --fast
# 或使用最小化配置
python3 sim/scene_generator.py  # 只运行场景生成器
```

### Q: C++ 编译报错（找不到 sim_capture.h）
```bash
# 确保 CMakeLists.txt 包含了 sim_capture.cpp
# 在 CMakeLists.txt 中添加：
# target_sources(traffic_edge PRIVATE sim_capture.cpp)
```
