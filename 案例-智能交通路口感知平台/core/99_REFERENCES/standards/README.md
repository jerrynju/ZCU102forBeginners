# 标准参考

> 适用的国家/行业标准与规范。

## 智能交通
- GB/T 28181-2016  公共安全视频监控联网系统信息传输、交换、控制技术要求
- GB 14886-2016  道路交通信号灯设置与安装规范
- GA/T 16.4  道路交通管理信息采集规范 第4部分：视频检测
- NTCIP 1202  Actuated Signal Controller Interface

## 网络协议
- MQTT v3.1.1 / v5.0
- mTLS (RFC 8446, TLS 1.3)
- CoAP (RFC 7252)

## 安全
- ISO 21434  汽车网络安全
- GB/T 22239-2019  信息安全技术 网络安全等级保护基本要求

## 工业
- IEC 61508  功能安全
- ISO 26262  汽车功能安全
