# 03 - AI 模型开发与 DPU 部署

## 1. 模型选型与技术路线

```
训练框架：PyTorch 2.x
模型架构：YOLOv8n / YOLOv8s（目标检测） + LPRNet（车牌识别）
量化工具：Vitis AI Quantizer（PyTorch 后训练量化 / QAT）
推理运行时：Vitis AI Runtime (VART) 3.x
目标硬件：ZCU102 DPU B4096
```

### 模型对比（在 DPU B4096 上的实测数据）

| 模型 | mAP50 | 推理耗时 | 模型大小 | 推荐场景 |
|------|-------|---------|---------|---------|
| YOLOv8n INT8 | 84.2% | 8ms | 3.2MB | 资源受限，实时性优先 |
| YOLOv8s INT8 | 88.5% | 18ms | 11MB | 精度与速度平衡（推荐） |
| YOLOv8m INT8 | 91.0% | 42ms | 26MB | 高精度场景 |
| LPRNet INT8 | 95.3% | 3ms | 1.8MB | 车牌识别专用 |

**选定方案：YOLOv8s + LPRNet 串行推理，总延迟 ~22ms/帧**

## 4. Vitis AI 量化流程

### 4.1 量化原理
Vitis AI 使用 **后训练量化（PTQ）** 结合 **量化感知训练（QAT）**：
- PTQ：快速，精度损失约 1-2%，适合精度余量充足的模型
- QAT：训练成本高，精度损失 < 0.5%，适合精度敏感场景

### 4.2 PTQ 量化步骤


## 5. LPRNet 车牌识别部署

### 5.1 模型结构

```
LPRNet 输入：96×24 RGB 车牌图像
LPRNet 输出：CTC 序列（最多 8 字符，含省份简称）

网络结构：
Input(3,24,96) → SmallBasicBlock×4 → GlobalAvgPool → Dense(68) → CTC
参数量：约 1.7M，INT8 后 1.7MB
```

```python
# ai/models/lprnet.py
import torch.nn as nn

class SmallBasicBlock(nn.Module):
    def __init__(self, in_ch, out_ch):
        super().__init__()
        self.layers = nn.Sequential(
            nn.Conv2d(in_ch, out_ch//4, 1),
            nn.BatchNorm2d(out_ch//4), nn.ReLU(),
            nn.Conv2d(out_ch//4, out_ch//4, (3,1), padding=(1,0)),
            nn.BatchNorm2d(out_ch//4), nn.ReLU(),
            nn.Conv2d(out_ch//4, out_ch//4, (1,3), padding=(0,1)),
            nn.BatchNorm2d(out_ch//4), nn.ReLU(),
            nn.Conv2d(out_ch//4, out_ch, 1),
            nn.BatchNorm2d(out_ch), nn.ReLU(),
        )
    def forward(self, x): return self.layers(x)

class LPRNet(nn.Module):
    CHARS = '京津沪渝冀豫云辽黑湘皖鲁新苏浙赣鄂桂甘晋蒙陕吉闽贵粤川青藏琼宁甯' \
            '0123456789ABCDEFGHJKLMNPQRSTUVWXYZ'
    NUM_CHARS = len(CHARS) + 1  # +1 for CTC blank

    def __init__(self):
        super().__init__()
        self.backbone = nn.Sequential(
            nn.Conv2d(3, 64, 3, padding=1), nn.BatchNorm2d(64), nn.ReLU(),
            nn.MaxPool2d(3, 1),
            SmallBasicBlock(64, 128),
            nn.MaxPool2d(3, (1,2)),
            SmallBasicBlock(128, 256),
            SmallBasicBlock(256, 256),
            nn.MaxPool2d(3, (1,2)),
            nn.Dropout(0.5),
            nn.Conv2d(256, 256, (1,4)),
            nn.BatchNorm2d(256), nn.ReLU(),
            nn.Dropout(0.5),
            nn.Conv2d(256, self.NUM_CHARS, (13,1)),
        )

    def forward(self, x):
        x = self.backbone(x)   # (B, C, 1, W)
        x = x.squeeze(2)       # (B, C, W)
        x = x.permute(2,0,1)  # (W, B, C) for CTC
        return x               # CTC 格式输出
```

## 6. 在 ZCU102 上运行推理

```cpp
// software/app/inference_engine.cpp
#include <vitis/ai/yolov8.hpp>
#include <vitis/ai/lprnet.hpp>
#include "shared_mem.h"

class InferenceEngine {
public:
    InferenceEngine() {
        // 加载 xmodel
        yolo_net_ = vitis::ai::YOLOv8::create(
            "/opt/models/yolov8s_traffic.xmodel", true);
        lpr_net_  = vitis::ai::LPRNet::create(
            "/opt/models/lprnet.xmodel", true);
    }

    DetectionResult_t run(uint8_t* frame_nv12, int channel) {
        // 1. NV12 → BGR（DPU 标准输入格式）
        cv::Mat yuv(DST_HEIGHT * 3/2, DST_WIDTH, CV_8UC1, frame_nv12);
        cv::Mat bgr;
        cv::cvtColor(yuv, bgr, cv::COLOR_YUV2BGR_NV12);

        // 2. YOLOv8 推理
        auto yolo_result = yolo_net_->run(bgr);

        // 3. 对检测到的车辆裁剪 ROI，送入 LPRNet
        DetectionResult_t result{};
        result.channel = channel;
        result.timestamp_us = get_timestamp_us();

        for (auto& box : yolo_result.bboxes) {
            auto& obj = result.objects[result.object_count++];
            obj.class_id   = box.label;
            obj.confidence = box.score * 100;
            obj.x = box.x * DST_WIDTH;
            obj.y = box.y * DST_HEIGHT;
            obj.w = box.width  * DST_WIDTH;
            obj.h = box.height * DST_HEIGHT;

            // 仅对车辆类别（0-2）识别车牌
            if (box.label <= 2 && box.score > 0.6f) {
                // 在检测框下半部分寻找车牌
                cv::Rect plate_roi(obj.x, obj.y + obj.h * 0.5,
                                   obj.w, obj.h * 0.5);
                plate_roi &= cv::Rect(0, 0, DST_WIDTH, DST_HEIGHT);
                if (plate_roi.area() > 0) {
                    cv::Mat plate_crop = bgr(plate_roi);
                    cv::resize(plate_crop, plate_crop, cv::Size(96, 24));
                    auto lpr_result = lpr_net_->run(plate_crop);
                    strncpy(obj.plate, lpr_result.plate_number.c_str(), 11);
                }
            }
        }
        return result;
    }

private:
    std::unique_ptr<vitis::ai::YOLOv8>  yolo_net_;
    std::unique_ptr<vitis::ai::LPRNet>  lpr_net_;
};
```

## 7. ByteTrack 多目标跟踪

```cpp
// software/app/bytetrack.cpp
// 基于 ByteTrack 算法实现跨帧目标跟踪
// 为每个目标分配稳定的 track_id，用于流量统计

#include "byte_tracker.h"

class TrafficTracker {
    ByteTracker tracker_;
    // 统计区域（虚拟线圈，用于流量计数）
    struct CountLine {
        int x1, y1, x2, y2;
        std::string direction;
        int count_in = 0, count_out = 0;
    };
    std::vector<CountLine> count_lines_;
    std::map<int, cv::Point2f> last_positions_;  // track_id → 上一帧位置

public:
    void update(DetectionResult_t& result) {
        std::vector<Object> objects;
        for (int i = 0; i < result.object_count; i++) {
            auto& o = result.objects[i];
            objects.push_back({
                .rect = cv::Rect(o.x, o.y, o.w, o.h),
                .label = o.class_id,
                .prob  = o.confidence / 100.f
            });
        }

        auto tracks = tracker_.update(objects);

        // 回填 track_id 到检测结果
        for (auto& track : tracks) {
            for (int i = 0; i < result.object_count; i++) {
                // IoU 匹配找到对应检测框
                if (iou(track.rect, result.objects[i]) > 0.5) {
                    result.objects[i].track_id = track.track_id;
                    // 虚拟线圈穿越检测
                    check_line_crossing(track, result.objects[i]);
                }
            }
        }
    }

private:
    void check_line_crossing(const STrack& track, ObjectResult& obj) {
        auto curr_pos = center_of(obj);
        if (last_positions_.count(track.track_id)) {
            auto prev_pos = last_positions_[track.track_id];
            for (auto& line : count_lines_) {
                if (crosses_line(prev_pos, curr_pos, line)) {
                    if (is_inbound(prev_pos, curr_pos, line))
                        line.count_in++;
                    else
                        line.count_out++;
                }
            }
        }
        last_positions_[track.track_id] = curr_pos;
    }
};
```

## 8. 模型优化技巧

### 8.1 DPU 利用率优化

```
问题：DPU 利用率不足（< 70%）
原因：前处理/后处理 CPU 成为瓶颈

解决方案：
1. 前处理移至 PL（HLS ISP 已完成格式转换）
2. 后处理（NMS）：
   - YOLOv8 的 NMS 在 PS 中用多线程并行处理
   - 或使用 HLS 实现 NMS IP（适合极致延迟场景）
3. 流水线化：4路摄像头轮询送 DPU，DPU 忙时用软件跟踪补帧
```
