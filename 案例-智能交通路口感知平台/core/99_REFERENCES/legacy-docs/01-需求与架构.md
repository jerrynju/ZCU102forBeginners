## 4. 数据流分析

```
输入带宽估算：
  4路 × 4K (3840×2160) × 30fps × 8bit × 3通道
  = 4 × 3840 × 2160 × 30 × 3 = 约 5.97 GB/s（原始）
  MIPI CSI-2 压缩后 ≈ 每路 ~1.5 Gbps（4 lane）
  → 需要 PL 内高速 AXI 通道，DDR4 带宽充足（51.2 GB/s）

推理吞吐估算：
  DPU B4096 @ 300MHz：4096 × 300M × 2 ops = 约 2.5 TOPS
  YOLOv8n INT8：~7 GOPS → 单帧约 2.8ms
  4路并行：目标 < 30ms/帧（含预处理 + 推理 + 后处理）

上行带宽：
  事件图片：每次违规上报 1 张 1080p JPEG ≈ 200KB
  统计数据：每分钟 JSON 包 < 1KB
  视频片段：触发式录制，H.264 1080p@15fps ≈ 2 Mbps
  → 10GbE 充裕，4G 备份带宽 50 Mbps 也可满足
```

## 5. 核心架构决策

### 5.1 PS/PL 功能划分原则

| 决策点 | 选择 | 理由 |
|--------|------|------|
| ISP 图像处理 | PL (HLS) | 4 路并行需要 >10 GB/s 吞吐，软件无法承担 |
| AI 推理 | PL (DPU) | 固定计算模式，FPGA 利用率 > 90%，延迟确定性强 |
| 目标跟踪 | PS A53 | 数据相关算法，FPGA 实现复杂度高，软件灵活性更重要 |
| 信号灯控制 | PS R5 | 需要硬实时（<10ms），R5 无 Linux 调度抖动 |
| 网络协议栈 | PS A53 | Linux 提供完整 TCP/IP + TLS 栈 |
| 10GbE MAC | PL (GTH) | 线速转发，PL 时序确定性 |

### 5.2 存储器分配方案

```
DDR4 4GB 分区规划（A53 Linux 视角）：

0x0000_0000 ~ 0x7FFF_FFFF  (2GB) - Linux OS + 应用程序 + 堆栈
0x8000_0000 ~ 0x8FFF_FFFF  (256MB) - 视频帧缓冲区（4路×3帧×4K NV12）
0x9000_0000 ~ 0x97FF_FFFF  (128MB) - DPU 输入/输出缓冲
0x9800_0000 ~ 0x9FFF_FFFF  (128MB) - AI 模型权重（预加载）
0xA000_0000 ~ 0xAFFF_FFFF  (256MB) - H.264 编码缓冲区
0xB000_0000 ~ 0xBFFF_FFFF  (256MB) - R5 OpenAMP 共享内存 (ECC 保护)
0xC000_0000 ~ 0xFFFF_FFFF  (1GB)   - 预留 / 未来扩展

R5 TCM (256KB) - FreeRTOS 内核 + 实时任务栈
```

### 5.3 总线带宽规划

```
PL → DDR4 (通过 AXI HP 端口):
  HP0: 视频 DMA 写入（摄像头 → DDR）      ~6 GB/s
  HP1: DPU 输入读取（DDR → DPU）          ~3 GB/s
  HP2: DPU 输出写入                       ~1 GB/s
  HP3: OSD/Display 读取                   ~1 GB/s

PS → DDR4 (通过 AXI HPC 端口):
  HPC0: A53 Linux DMA（网络收发）
  HPC1: A53 应用内存访问

总理论带宽：DDR4-2400 × 64bit = 38.4 GB/s（实测利用率 ~60%）
```

## 6. 接口规范

### 6.1 PL 引脚分配（主要接口）

```
MIPI CSI-2 (J55 FMC HPC):
  CAM0: DATA_P/N[0:3], CLK_P/N  (LVDS, 1.2V)
  CAM1: DATA_P/N[0:3], CLK_P/N
  CAM2: DATA_P/N[0:1], CLK_P/N  (2 lane, 1080p)
  CAM3: DATA_P/N[0:1], CLK_P/N

GTH Transceiver (10GbE):
  TX_P/N: 使用 GTH Bank 226 Lane 0/1
  RX_P/N: 使用 GTH Bank 226 Lane 0/1
  参考时钟: 156.25 MHz (Si5338)

DisplayPort:
  ZCU102 板载 DP 接口 (PS MIO 27:28)

CAN Bus:
  PL GPIO → 外部 SN65HVD230 CAN PHY → J87 扩展口
```
