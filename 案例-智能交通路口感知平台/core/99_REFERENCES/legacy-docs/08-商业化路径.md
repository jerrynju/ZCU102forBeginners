### 1.2 定价方案

```
方案 A：硬件销售 + 年度软件维保
  硬件售价：$2,200（毛利率 ~67%）
  年度维保：$300/台/年（含固件更新 + 技术支持）

方案 B：硬件 + 平台订阅（推荐）
  硬件售价：$1,500（较低吸引客户）
  平台订阅：$80/台/月（数据分析 + 违规上报 + 云端存储）
  3年 LTV = $1,500 + $80×36 = $4,380 → 毛利约 $2,600

方案 C：解决方案整包（含集成服务）
  路口整包价：$8,000 ~ $15,000（含 4 路摄像头安装调试）
  后续运维：SLA 4 小时响应，$500/台/年
```

## 4. 就业技能覆盖矩阵

本案例覆盖当前嵌入式 / FPGA / AI 就业市场的主流技术栈：

### FPGA / 硬件方向

| 技能 | 在案例中的体现 | 市场需求 |
|------|-------------|---------|
| Vivado Block Design | 顶层 BD 搭建、IP 集成 | 必备 |
| Vitis HLS | ISP 管线、OSD IP | 高薪核心技能 |
| AXI 总线协议 | AXI4 / AXI4-Stream / AXI4-Lite | 必备 |
| MIPI CSI-2 | 4路摄像头接入 | 视觉方向必备 |
| GTH SerDes | 10GbE PHY 层 | 高速通信方向 |
| 时序收敛 | XDC 约束、物理优化 | 资深工程师必备 |
| DPU 集成 | DPU TRD 部署 | AI FPGA 热门 |
| 安全设计 | 加密启动、eFUSE | 商业项目必备 |

## 5. 学习路径建议

```
阶段 1（1-2个月）：基础验证
  目标：ZCU102 跑通 PetaLinux，用 DPU 跑 YOLOv8 demo
  产出：/dev/video 出图，DPU 推理延迟数据

阶段 2（2-3个月）：单模块攻坚
  选择一个方向深入：
  □ FPGA 路线：实现 HLS ISP → 集成到 VDMA → 优化时序
  □ 软件路线：完整 V4L2 驱动 → 多线程推理管线 → MQTT 上报
  □ AI 路线：完整量化流程 → 精度分析 → 多模型级联

阶段 3（2-3个月）：系统集成
  将各模块连接成端到端系统：
  摄像头 → FPGA ISP → DPU → ByteTrack → MQTT → Web UI

阶段 4（1-2个月）：商业化能力
  安全启动 + OTA + 工厂测试脚本
  → 可演示完整的从开发到量产的闭环能力

完成后可获得的能力标签：
  "Zynq UltraScale+ 全栈开发"
  "Vitis AI 边缘部署"
  "嵌入式 Linux + RTOS 异构开发"
  "智慧交通边缘计算"
```
