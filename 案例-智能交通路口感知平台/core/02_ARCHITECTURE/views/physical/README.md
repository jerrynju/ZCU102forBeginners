# 物理/部署视图

> 4+1 视图中的物理视图，关注 **硬件连接、部署形态、物理位置**。

## 设备物理组成

```
┌────────────────────── ZCU102 边缘感知盒 ──────────────────────┐
│                                                                │
│  外部接口 (前视图)                                             │
│  ┌────────────────────────────────────────────────────────┐    │
│  │  [CAM0]  [CAM1]  [CAM2]  [CAM3]    4×MIPI CSI-2 接口   │    │
│  │  [USB3]  [DP]    [10GbE] [GPS]      1×USB3 + 1×DP + 光口 │    │
│  │  [CAN]   [PWR]   [RESET] [JTAG]     1×CAN + 电源 + 调试 │    │
│  └────────────────────────────────────────────────────────┘    │
│                                                                │
│  内部板卡（侧视图）                                            │
│  ┌─────────────────────────────────────────────┐              │
│  │  ZCU102 主板 (Xilinx)                        │              │
│  │    ├── Zynq UltraScale+ XCZU9EG              │              │
│  │    │    ├── PL：4×ISP HLS + DPU + 10GbE MAC │              │
│  │    │    └── PS：A53 (Linux) + R5 (FreeRTOS) │              │
│  │    ├── DDR4 4GB (2× 2GB)                    │              │
│  │    ├── eMMC 32GB                            │              │
│  │    ├── SFP+ 光模块槽位                       │              │
│  │    ├── DisplayPort 输出                      │              │
│  │    ├── USB3.0 Hub                            │              │
│  │    └── PMIC + 散热片                         │              │
│  │  FMC 子板 (MIPI CSI-2 4 路)                  │              │
│  │  4G/5G 模组 (USB 形态)                       │              │
│  │  CAN PHY 子板 (SN65HVD230)                   │              │
│  │  GPS 模组 (u-blox NEO-M8N)                   │              │
│  └─────────────────────────────────────────────┘              │
│                                                                │
│  外壳                                                          │
│  ├── 铝合金压铸，IP54 防尘防水                                  │
│  ├── 工作温度：-20°C ~ +70°C                                   │
│  ├── 散热：铝挤 + 自然散热（功耗 < 35W）                       │
│  └── 安装：抱杆 / 挂壁                                         │
└────────────────────────────────────────────────────────────────┘
```

## 物理接口表

| 接口 | 数量 | 位置 | 用途 |
|------|------|------|------|
| MIPI CSI-2 | 4 | 前视图 | 摄像头 |
| USB3.0 | 1 | 前视图 | 备用摄像头 / 4G 模组 |
| DisplayPort | 1 | 前视图 | 本地监视器 |
| SFP+ | 1 | 前视图 | 10GbE 上联 |
| SMA | 1 | 前视图 | GPS 天线 |
| DB9 | 1 | 前视图 | CAN 总线 |
| RJ45 | 1 | 前视图 | PS-GEM 调试（仅调试）|
| 电源 | 1 | 前视图 | DC 12V/5A |
| JTAG | 1 | 侧视图 | 工厂烧录（量产后禁用）|

## PCB 层叠

- 8 层板
- 顶层 + 底层：高速信号（MIPI、GTH）
- 内层 2/7：地平面
- 内层 3/6：电源平面
- 内层 4/5：低速信号 + 电源分割
