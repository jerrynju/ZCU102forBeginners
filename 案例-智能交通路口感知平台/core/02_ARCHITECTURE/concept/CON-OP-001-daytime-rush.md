# CON-OP-001: 日间高峰运行场景

## 时间
工作日 07:00-09:00, 17:00-19:00

## 流量预期
- 机动车：~3000 辆/小时/方向
- 行人：~500 人/小时/方向
- 非机动车：~800 辆/小时/方向

## 系统行为

1. **采集**：4 路 4K@30fps 同步
2. **检测**：
   - 4 路轮询送 DPU，单路 18ms
   - DPU 利用率 ~78%
3. **跟踪**：
   - 单帧跟踪 < 2ms
   - 同时跟踪目标 ≤ 64
   - 触发 ID 切换保护
4. **事件检测**：
   - 闯红灯、逆行、违规停车、行人闯红灯
   - 单事件处理 < 5ms
5. **云端上报**：
   - 流量统计 1/min
   - 事件实时
   - 状态 1/10s
6. **本地显示**：
   - 4K 合成画面 + 检测框叠加
   - 10fps 推流到 Web UI

## 性能指标
- 单帧端到端延迟：< 30ms
- 云端事件延迟：< 500ms
- 整机功耗：< 35W
- CPU 占用：~60%

## 异常处理
- DPU 过热 → 降级到 YOLOv8n
- 云端断连 → 启用离线缓存
- 信号灯控制器无响应 → 切安全模式
