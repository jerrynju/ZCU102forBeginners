# DES-ARCH-009: 事件检测状态机

## 事件类型

| 事件 | 检测方法 | 依赖 |
|------|---------|------|
| 闯红灯 | 红灯 + 车辆越过停车线 | 跟踪 + 信号灯状态 |
| 逆行 | 轨迹方向 vs 道路方向偏差 > 150° | 跟踪（>5 帧轨迹）|
| 违规停车 | 目标在禁止区停留 > 30s | 跟踪 + 区域配置 |
| 占用公交车道 | 非公交车辆进入公交道 > 5s | 跟踪 + 车道配置 |
| 行人闯红灯 | 红灯 + 行人越过斑马线 | 跟踪 + 信号灯状态 |
| 拥堵 | 排队长度 > 50m | 跟踪（聚类）|

## 状态机（以闯红灯为例）

```
         ┌──────────┐
         │  正常    │ ◄────────────────┐
         └────┬─────┘                  │
              │ 红灯 + 车辆接近         │
              ▼                        │
         ┌──────────┐                  │
         │  警告    │ ── 离开 →──────►─┤
         └────┬─────┘                  │
              │ 越过停车线             │
              ▼                        │
         ┌──────────┐                  │
         │  违章    │ ── 上报 + 锁定 ─►│
         └──────────┘
```

## 区域配置

每路摄像头支持配置：
- 停车线（多边形）
- 斑马线（多边形）
- 禁止区（多边形）
- 车道方向（向量）
- 公交专用道（多边形）
